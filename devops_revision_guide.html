Experiment 01: Source Code Management & Collaboration (Git)

Date: 09-09-2026 | Page No: 01–02

Aim: Initialize the Git repository to perform core version control operations (add, commit, log) and simulate a multi-branch workflow to trigger, analyze and manually resolve merge conflicts.

BASE & BRANCH CODE

master branch:

def calculator(a, b):
    return a + b

print(calculator(5, 3))

b1 branch:

def add(a, b):
    return a + b

print(add(5, 3))

b2 branch:

def cal(a, b):
    return a + b

print(cal(5, 3))
CONFLICT MARKERS ANATOMY

When merging b2 into master after b1:

<<<<<<< HEAD (Current Change)
def add(a, b):
    return a + b
print(add(5, 3))
=======
def cal(a, b):
    return a + b
print(cal(5, 3))
>>>>>>> b2 (Incoming Change)

Resolution: Delete markers <<<<<<<, =======, >>>>>>>, keep desired version, then stage & commit.

  • 1

    Create Project Folder

    Create a new folder on Desktop (e.g. program-1).

  • 2

    Launch VS Code

    Open the folder, in place of the Windows Explorer folder path/URL type cmd → in command prompt type code ..

  • 3

    Create Source Code File

    In VS Code, create a file with .py extension: calculator.py. Write the simple calculator function.

  • 4

    Initialize & Base Commit on Master

    In VS Code open the terminal (Ctrl + `) and execute:

    git init
git add .
git commit -m "second"

    Check active branch: git branch (displays * master or * main).

  • 5

    Create Feature Branches b1 and b2

    Execute:

    git branch b1
git branch b2
  • 6

    Switch to b1 & Commit Changes

    Execute: git switch b1 (b1 file opens). Modify calculator.py to use function name def add(a, b):. Then execute:

    git add .
git commit -m "branch 1"
  • 7

    Switch to b2 & Commit Conflicting Changes

    Execute: git switch b2 (b2 file opens). In calculator.py on the exact same lines, change function name to def cal(a, b):. Then execute:

    git add .
git commit -m "branch 2"
  • 8

    Switch back to Master

    Execute: git switch master. Verify active branch using git branch.

  • 9

    Fast-Forward Merge b1

    Execute: git merge b1. Output will state Fast-forward (no conflicts because master had no other commits).

  • 10

    Trigger Merge Conflict with b2

    Execute: git merge b2. Terminal outputs:

    Auto-merging calculator.py

Automatic merge failed; fix conflicts and then commit the result.
  • 11

    Resolve Conflict & Finalize Commit

    Open calculator.py. Choose Accept Current, Accept Incoming, or manually remove markers. Then conclude merge in terminal:

    git add .
git commit -m "conflict resolved"
git status   # Displays: "nothing to commit, working tree clean"

Experiment 02: Automated Build & Dependency Management using Apache Maven

Date: 21-09-2026 | Page No: 03–04

Aim: Construct a build and standard Java project structure to manage dependencies via pom.xml and automate the build lifecycle - specifically compilation, unit testing, and packaging to generate deployable artifacts.

POM.XML DEPENDENCY (JSON-SIMPLE)
<dependencies>
    <dependency>
        <groupId>com.googlecode.json-simple</groupId>
        <artifactId>json-simple</artifactId>
        <version>1.1.1</version>
    </dependency>
</dependencies>

Paste inside <dependencies> tag after the default junit dependency.

JSON/STUDENT.JSON DATA FILE

Created in folder JSON/ at the project root level:

{
    "firstname": "Khushi",
    "lastname": "M"
}
  • 1

    Create Maven Project in Eclipse

    Open Eclipse → File → New → Maven Project → Click Next.

  • 2

    Select Archetype & Catalog

    In Catalog dropdown select Internal (or All Catalogs and filter quickstart) → select maven-archetype-quickstart → Click Next.

  • 3

    Enter Project Coordinates

    Group Id: mod1 → Artifact Id: mod1 (or your chosen name) → Click Finish. (If console prompts for input during archetype generation, type y and press Enter → BUILD SUCCESS).

  • 4

    Create JSON Data Folder & File

    Right-click the Maven project root → New → Folder named JSON. Right-click JSON folder → New → File named student.json. Write the JSON object with firstname and lastname.

  • 5

    Add Dependency in pom.xml

    Open pom.xml → Add the json-simple 1.1.1 dependency block inside <dependencies> → Save file (Ctrl + S). Maven automatically downloads the jar into Maven Dependencies.

  • 6

    Create Java Class readjson.java

    Expand src/test/java (or src/main/java) → right-click package → New → Class → Name: readjson → Check public static void main(String[] args) → Finish.

    Write the following parsing code:

    package mod1;
import java.io.FileReader;
import org.json.simple.JSONObject;
import org.json.simple.parser.JSONParser;

public class readjson {
    public static void main(String[] args) throws Exception {
        JSONParser jsonparser = new JSONParser();
        FileReader reader = new FileReader(".\\JSON\\student.json");
        Object obj = jsonparser.parse(reader);
        JSONObject studentobj = (JSONObject) obj;
        String fname = (String) studentobj.get("firstname");
        String lname = (String) studentobj.get("lastname");
        System.out.println("Firstname : " + fname);
        System.out.println("Lastname : " + lname);
    }
}
  • 7

    Run & Verify Output

    Right-click readjson.java → Run As → Java Application.
    Console outputs: 

    Firstname : Khushi
Lastname : M

Experiment 03: Application Containerization using Docker

Date: 03-10-2026 | Page No: 05

Aim: Create a Dockerfile to package static web assets into an Apache format container, configuring the environment to serve HTML content and distributing the finalized image to container registry.

DOCKERFILE (NO EXTENSION)
FROM httpd:latest
COPY index.html /usr/local/apache2/htdocs/

Critical: Ensure the trailing slash / is present on htdocs!

INDEX.HTML WEB ASSET
<!DOCTYPE html>
<html>
<head><title>DevOps Docker Test</title></head>
<body>
  <h1>Docker Web Application Container</h1>
  <p>Hosted on Apache HTTPD in Docker</p>
</body>
</html>
  • 1

    Prerequisites

    Open Docker Desktop in Windows and ensure the Docker engine is running (green status). Sign in to Docker Desktop and Docker Hub in your browser.

  • 2

    Create Directory & Files

    Create a folder named Docker on Desktop. Open it in VS Code. Create Dockerfile (no extension) and index.html.

  • 3

    Build Local Container Image

    Open terminal in VS Code inside the Docker folder and run:

    docker build -t my-app .

    (Do not omit the dot . at the end — it represents the build context).

  • 4

    Run Container on Port 49153

    Run the container in detached mode mapped to port 49153:

    docker run -d --name c1 -p 49153:80 my-app

    Verify by opening http://localhost:49153 in your browser. Your custom HTML page displays.

  • 5

    Tag Image for Docker Hub

    Check image ID with docker images, then tag the image with your Docker Hub username:

    docker tag my-app ommd3076/my-app:latest
  • 6

    Push Image to Docker Hub Registry

    Log in via CLI if not logged in (docker login) and push:

    docker push ommd3076/my-app:latest

    Verify the repository on hub.docker.com.

  • 7

    Pull Image & Run on Secondary Port (9094)

    Pull the published image from Docker Hub and run it on port 9094:

    docker pull ommd3076/my-app:latest
docker run -d --name c2 -p 9094:80 ommd3076/my-app:latest

    Verify in browser at http://localhost:9094.

FATAL CRASH

Slack Integration: "Test Connection Failed"

THE PREVIOUS CHATGPT BROWSER FIX

Root Cause: (1) Pasting full URL https://workspace.slack.com into Jenkins "Workspace" field. (2) Saving the Slack integration token as "Username with password" instead of Secret text. (3) Channel name missing the # prefix.

The Resolution:
1. In Jenkins Manage Jenkins → System → Slack, enter subdomain only (e.g. om-devops, never slack.com).
2. Add credential as Secret text, paste the Integration Token from Slack App step 3.
3. Set Default channel to #channel-name.
4. Ensure the Jenkins CI app is explicitly added to the channel inside Slack.

02
SILENT BUG

Docker: Container Shows "It Works!" Instead of HTML

DOCKER DESKTOP TRAP

Root Cause: (1) Clicking "Run" on the base image httpd instead of your built custom image (my-app) in Docker Desktop UI. (2) Dockerfile copy path missing the trailing slash /usr/local/apache2/htdocs/.

The Resolution:
1. In Docker Desktop, go to Containers, delete running container.
2. Go to Images tab, ensure you launch your custom tagged image, NOT httpd.
3. Hard refresh browser using Ctrl + F5 to bypass cached Apache static page.

03
POWERSHELL SYNTAX

Jenkins Password: "'C:\Program' is not recognized"

OCT 15 LAB ATTEMPT

Root Cause: Executing unquoted file path C:\Program Files\Jenkins\secrets\... directly in PowerShell terminal. PowerShell treats the space after "Program" as an argument separator.

The Resolution: Use the Get-Content cmdlet with double quotes:
Get-Content "C:\Program Files\Jenkins\secrets\initialAdminPassword"
(Note: File has NO .txt extension. Do not append .txt).

04
GIT MERGE TRAP

Git: "You are still merging" or Editor Staged Markers

VS CODE MERGE EDITOR

Root Cause: Closing the merge conflict editor without clicking "Complete Merge", or leaving raw <<<<<<< HEAD markers in the file.

The Resolution:
1. Open calculator.py, manually verify no conflict markers exist.
2. In terminal run: git add . followed by git commit -m "conflict resolved".
3. Run git status to confirm "working tree clean".

ECLIPSE WORKING DIR

03 / Actual Teacher Viva Questions

Exact Viva Questions Recorded in Lab Sessions.

The exact questions asked by your teacher in previous chats, organized by practical. Direct, crisp answers for maximum marks.

Q01What is Git and why is it used in DevOps?
Git is a distributed version control system that tracks source code changes over time, allows parallel multi-branch development, enables traceability of every change, and integrates with CI/CD tools to trigger automated testing and builds.
Q02What is the difference between Git and GitHub?
Git is the local version control command-line tool installed on your machine. GitHub is a cloud-based hosting platform that stores remote Git repositories and provides collaboration tools, pull requests, and webhooks.
Q03What is the purpose of branches (b1, b2, master)?
Branches allow developers to work on new features, bug fixes, or experiments in total isolation without destabilizing the production code on the master (or main) branch.
Q04What is the difference between git switch and git checkout?
git switch was introduced in Git 2.23 specifically to switch or create branches safely. git checkout is an older overloaded command used for switching branches, checking out older commits, and restoring modified files.
Q05What is a Fast-Forward merge?
A Fast-Forward merge happens when the target branch (e.g. master) has no new commits since the feature branch was created. Git simply moves the master pointer forward to the tip of the feature branch without creating an extra merge commit.
Q06When does a Merge Conflict occur?
A merge conflict occurs when two different branches modify the exact same lines of code in the same file and then both try to merge into a common branch. Git cannot determine which version to keep automatically.
Q07Explain the conflict markers: <<<<<<< HEAD, =======, and >>>>>>> b2.
<<<<<<< HEAD marks the code in the currently checked-out branch (master). ======= is the separator between conflicting versions. >>>>>>> b2 marks the incoming code from branch b2.
Q08How do you resolve a merge conflict in Git?
Open the file, delete the conflict markers (<<<<<<<, =======, >>>>>>>), choose or combine the code, save the file, and then run git add . followed by git commit -m "conflict resolved".
Q09What does git status show during an unresolved merge conflict?
It lists the conflicting file in red under "Unmerged paths: both modified: calculator.py" and warns "fix conflicts and run git commit".
Q10What does git push -u origin main mean?
The -u flag sets the upstream tracking reference. It links the local main branch to the remote origin/main branch so future pushes only require typing git push.
Q11What is the difference between git pull and git fetch?
git fetch downloads remote commits to your local repo without merging them into your working files. git pull runs git fetch and immediately executes git merge into your active branch.
Q12How do you abort a merge if you make a mistake?
Run git merge --abort. This immediately reverts the working files and repo state back to before the merge started.
Q01What is a Maven project? (Teacher Question)
A Maven project is a Java project whose build, testing, dependencies, and packaging are defined declaratively in an XML file called pom.xml. Maven provides a standardized project layout and automates the build process.
Q02What is the Maven project structure? (Teacher Question)
Standard structure: src/main/java (application source code), src/main/resources (config files), src/test/java (test code like JUnit), pom.xml (root configuration file), and target/ (compiled .class files and packaged .jar artifacts).
Q03What is pom.xml? (Teacher Question)
POM stands for Project Object Model. It is the fundamental configuration file in Maven that specifies project coordinates (groupId, artifactId, version), dependencies, plugins, and build goals.
Q04What is the use of Maven in DevOps? (Teacher Question)
Maven eliminates manual jar file downloads, enforces uniform compilation and unit testing across all developer machines, and provides predictable CLI commands (mvn clean package) that CI servers like Jenkins execute to build and package applications automatically.
Q05What is the Maven build lifecycle? (Teacher Question)
The build lifecycle is a sequence of defined phases: validate → compile → test → package → verify → install → deploy. Running any phase automatically executes all preceding phases in sequence.
Q06Explain Maven & dependency management. (Teacher Question)
Instead of manually downloading and adding .jar files to the classpath, you declare library coordinates in pom.xml. Maven automatically downloads the required jars from Maven Central into the local ~/.m2 repository, along with all their transitive dependencies.
Q07What is the role of Maven in a DevOps pipeline? (Teacher Question)
Maven serves as the automated build engine inside CI/CD pipelines: Jenkins checks out code from Git → triggers Maven to compile code → executes unit tests → packages the code into a deployable .jar or .war artifact.
Q08Outline the difference between Git & Maven working. (Teacher Question)
Git is for source code version control (tracking code history, commits, branches). Maven is for build automation and dependency resolution (compiling, running tests, and bundling code into executable jars). Git manages the source; Maven builds it.
Q09What are Maven coordinates (groupId, artifactId, version)?
They uniquely identify an artifact: groupId is the organization domain (e.g. com.googlecode.json-simple), artifactId is the project name (json-simple), and version is the release tag (1.1.1).
Q10What is a Maven Archetype?
An archetype is a project templating toolkit (such as maven-archetype-quickstart) that generates the standard directory structure and starter pom.xml for a new project.
Q11In your program, what do JSONParser and JSONObject do?
JSONParser reads the character stream from FileReader and parses it into an Object. We cast it to JSONObject (a key-value map) to extract fields via studentobj.get("firstname").
Q12What is the difference between mvn compile and mvn package?
mvn compile only compiles the Java source files in src/main/java into .class files. mvn package compiles, executes unit tests, and bundles the compiled code into a distributable .jar or .war in the target/ directory.
Q01What is Docker? (Teacher Question)
Docker is an open-source containerization platform that packages an application and all its dependencies, runtime, and libraries into a standardized lightweight container that runs identically in any environment.
Q02Why do we need Docker? (Teacher Question)
To eliminate the classic "it works on my machine" problem. Docker ensures environment consistency between a developer's laptop, testing servers, and production clouds without hardware virtualization overhead.
Q03What is the importance of Docker in DevOps? (Teacher Question)
Docker provides lightweight isolation, boots in milliseconds, drastically reduces infrastructure costs compared to VMs, enables rapid CI/CD automated deployments, and forms the foundation for container orchestration (Kubernetes).
Q04What is the difference between a Docker Image and a Docker Container?
A Docker Image is a read-only, immutable template built from layered instructions. A Docker Container is an active, runnable, stateful instance of an image with a thin writable top layer.
Q05What is a Dockerfile and what does FROM httpd:latest mean?
A Dockerfile is a text recipe containing instructions to build an image. FROM httpd:latest sets the official Apache HTTP Server image as the base image for our container.
Q06What does COPY index.html /usr/local/apache2/htdocs/ do?
It copies our local custom index.html web page from the host machine into Apache's default public web root folder inside the container image.
Q07In docker run -d --name c1 -p 49153:80 my-app, explain each flag.
-d runs in background (detached mode). --name c1 gives the container a friendly name. -p 49153:80 maps port 49153 on the host laptop to port 80 inside the container. my-app is the image to run.
Q08Which is the host port and which is the container port in -p 49153:80?
The format is host_port:container_port. 49153 is the port opened on your physical machine; 80 is Apache's internal container listening port.
Q09Why must you tag an image before pushing to Docker Hub?
Docker Hub routes images by account namespace. You must tag the image as username/repository:tag (e.g. ommd3076/my-app:latest) so Docker knows where to publish the image.
Q10Why did Apache display "It works!" instead of your custom HTML?
Because in Docker Desktop, the base image httpd was launched by mistake instead of our custom built image my-app, or the trailing slash was omitted in /usr/local/apache2/htdocs/, or the browser cached the static page.
Q11What is the command to view running vs all containers?
docker ps displays only active/running containers. docker ps -a displays all containers, including stopped and exited containers.
Q12What is Docker layer caching?
Each command in a Dockerfile creates an immutable filesystem layer. When re-running docker build, Docker reuses unchanged layers from previous builds, speeding up the build from minutes to seconds.
Q01What is Continuous Integration (CI) and why do we use Jenkins?
CI is an engineering practice where code changes are continuously merged into a shared repo and validated by automated builds and tests. Jenkins is the leading automation server that orchestrates this entire pipeline automatically.
Q02What is Polling (Poll SCM)? (Teacher Question)
Polling is a pull-based build trigger where Jenkins periodically queries the GitHub repository on a scheduled timer (using cron syntax, e.g. H/5 * * * * every 5 mins) to check if any new commits were pushed. If changes exist, Jenkins starts a build.
Q03What is a Webhook and how does it differ from Polling? (Teacher Question)
A Webhook is push-based: GitHub immediately sends an HTTP POST request to Jenkins the exact second a developer pushes code. Difference: Polling introduces delays and wastes server CPU asking repeatedly; Webhooks trigger instant, real-time builds without polling overhead.
Q04Where is the Jenkins initial admin password located on Windows? (Teacher Question)
In C:\Program Files\Jenkins\secrets\initialAdminPassword or C:\ProgramData\Jenkins\.jenkins\secrets\initialAdminPassword. (It is a text file with no .txt extension).
Q05Why did PowerShell give "'C:\Program' is not recognized" when getting the password?
Because the path contains a space between "Program" and "Files". Without double quotes, PowerShell treated C:\Program as the command name. The fix is: Get-Content "C:\Program Files\Jenkins\secrets\initialAdminPassword".
Q06What is the default port for Jenkins and how do you access it?
Default port is 8080, accessed in the web browser at http://localhost:8080.
Q07What is a Freestyle project in Jenkins?
A Freestyle project is a configurable build job created and managed entirely through the Jenkins web UI with form fields for SCM, build triggers, batch/shell commands, and post-build actions.
Q08What does the branch specifier */main mean in Jenkins?
It tells the Git plugin to build the main branch from any remote repository (the wildcard * matches remote tracking origin).
Q09What batch commands did you configure in the build step?
Under Execute Windows batch command: (1) java --version (verifies JRE), (2) javac test.java (compiles Java file), and (3) java test (runs class and verifies output).
Q10What does Console Output in Jenkins show?
It shows the real-time standard output log of the build, including Git checkout hash, commands executed, compiler messages, and final status (Finished: SUCCESS or FAILURE).
Q11What is the difference between build status SUCCESS, UNSTABLE, and FAILURE?
SUCCESS (blue/green ball): All compile and test steps passed. UNSTABLE (yellow ball): Build finished but unit tests failed. FAILURE (red ball): Compilation crashed or script threw an error.
Q12What is a Jenkins Workspace?
A dedicated folder on the Jenkins controller disk (under workspace/<job-name>) where Jenkins clones the Git repository and executes the build scripts.
Q01Why integrate Jenkins with Slack in a DevOps workflow? (Teacher Question)
It implements ChatOps: automated pipeline notifications are pushed instantly to the team's Slack channel. Developers know immediately if a build broke without having to log in to Jenkins.
Q02Which plugin is used in Jenkins for Slack integration?
The official Slack Notification Plugin, installed via Manage Jenkins → Plugins.
Q03What app must be installed in your Slack workspace?
The Jenkins CI integration app from the Slack App Directory.
Q04What is the Slack Integration Token and where do you get it?
It is an authentication secret generated in Step 3 of the Jenkins CI app setup inside Slack after you select the destination channel. Jenkins uses it to authorize incoming alert messages.
Q05What credential type must you select in Jenkins to store the Slack token?
Secret text. You paste the Slack Integration Token into the "Secret" field and give it an ID (e.g. admin or slack-token).
Q06What must be entered into the Jenkins Slack "Workspace" field?
Only the team domain / subdomain prefix (e.g. om-devops). You must NEVER enter the full URL like https://om-devops.slack.com.
Q07Why did your Slack "Test Connection" fail previously? (The ChatGPT Browser Fix)
Three exact reasons: (1) Entering full URL instead of subdomain in Workspace, (2) storing the token as Username/Password instead of Secret text, and (3) omitting the # prefix from channel name (must be #devops).
Q08How must channel names be formatted in Jenkins Slack settings?
With a hash prefix for public channels: #channel-name (e.g. #devops), or @username for direct user notifications.
Q09What are Post-build Actions in a Jenkins job?
Steps executed automatically after the main build commands finish, regardless of success or failure. In our lab, we added Slack Notifications as a post-build action.
Q010Which checkboxes did you enable under Slack Notifications in the job?
Notify Build Start, Notify Success, Notify Failure, and Notify Every Failure.
Q011What exact message appears in Slack when you click Build Now?
First: Starting build #... by user admin. Then upon completion: a green vertical bar with SUCCESS after 1 sec and a direct link to the Jenkins build.
Q012What is ChatOps?
ChatOps is an operational collaboration model that places automated bots, alerts, and operational tooling directly inside group chat platforms (like Slack) so developers and operations collaborate transparently in real time.
